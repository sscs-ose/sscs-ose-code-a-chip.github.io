- `raw`: unsigned code

- `sm3`: sign-magnitude, magnitude clamped to 3 bits (x=0 -> -7 at zp 8)
- `tc`: two's complement x-zp, strict all-zero planes
- `tcse`: two's complement x-zp, sign-extension planes also skipped

Fraction of 32-row tiles whose top bit-plane is entirely skippable, with migration, all 12 layers: sign-magnitude 94.6%, 3-bit sign-magnitude 2.6%, two's complement 0.0%.

After migration only 17.8% of activation codes sit at the zero point (all layers), so the only encoding that skips cycles is sign-magnitude of (x - zero point), at 3.03 cycles out of 4. Two's complement skips almost nothing (4.00). Large savings (0.97 cycles, sign-magnitude) appear only without migration, where accuracy has already collapsed (see table_accuracy.md). We did not cost the sign-magnitude recoding in hardware and did not build skipping.
