# Teaching scene previews

These SVGs were exported from real controller snapshots. Both examples start
with x2=0, so the offset 8 gives effective address 0x08. The read demo uses
`lw x5,8(x2)` with explicitly seeded address 8 = 1. The write demo uses
`sw x1,8(x2)` after loading x1 = 1. All circuit states are logical educational
states. Matching PNGs are provided for visual review.
