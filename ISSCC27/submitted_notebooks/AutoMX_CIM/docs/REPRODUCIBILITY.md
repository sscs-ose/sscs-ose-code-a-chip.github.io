# Reproducing the submitted laboratory

Copyright 2026 EDABK Laboratory.

The submitted notebook is the frozen 509-cell final laboratory. Its saved
output is readable without running tools. Packaging changes author/contact
metadata and supporting documentation; code cells and measured outputs are
preserved. The original completed Run All is recorded in `results/execution/`.
Packaging validation and the short RTL/layout check are separate checks.

## Runtime inputs

`AutoMX_CIM_runtime_inputs_20261030.tar.gz` contains the exact prepared
`inputs/`, analog/digital SKY130 PDKs, pinned OpenLane source and Docker
image, shared ngspice 44.2 library, Netgen, OpenSTA source/build and Python
wheel inputs, and the UCI HAR dataset. It contains no old `runs/` or
`experiments/` directory and no old routed parent checkpoint. Declared hard
macro IP and benchmark fixtures remain inputs. Download the archive from the
[Google Drive reproduction-assets folder](https://drive.google.com/drive/folders/182dkLchafQBx1tNYUVZpyNpNAvFWwNjB?usp=drive_link)
using a browser, then restore the downloaded local file with:

```bash
python scripts/restore_runtime.py --archive /path/to/AutoMX_CIM_runtime_inputs_20261030.tar.gz
```

`runtime_assets.json` records the shared folder, exact archive filenames,
byte counts and publication state. Public link-reader permissions for the
folder and both archives were verified through Drive metadata on 31 October
2026; a complete archive download was not performed. The Drive folder is a browser
page: use manual download followed by `--archive`. If an individual direct
HTTPS archive URL is supplied separately, the restore script also supports
`--url URL`. See [reproduction assets](../RELEASE_ASSETS.md).

`AutoMX_CIM_measurement_records_20261029.tar.gz` is optional for execution.
It preserves detailed numerical records, logs, waveforms in NPZ format,
emitted circuit/RTL/tool scripts and figures from the completed final run.
It omits redundant GDS/ODB/DEF/SPEF, raw simulator dumps, VCD and compiled
executables; these are generated by fresh execution. The archive is not a
byte-for-byte backup of the entire development directory.

## Host and Python

Use Linux x86-64 with Docker available to the current user. Install native
`iverilog`/`vvp`, `ngspice`, `klayout`, `magic`, `tclsh` and the ordinary
shared-library dependencies of the packaged tools. Their versions are in
the measurement-toolchain document and the captured environment receipts.
`standalone.json` pins the OpenLane image; `docs/opensta_version.json` pins
the clock-aware power engine. The notebook can load the bundled Docker
image when it is absent; no old design checkout is required.

```bash
conda env create -f environment.yml
conda activate automx-review
export AUTOMX_PYTHON="$CONDA_PREFIX/bin/python"
python -m ipykernel install --prefix "$CONDA_PREFIX" --name python3 --display-name "Python 3 (AutoMX-CIM)"
./run_notebook.sh
```

Choose the Python kernel from this environment and use Restart Kernel &
Run All. `./run_all.sh` performs the same complete execution headlessly.
The launchers used `env_mamba` on the acquisition host; `AUTOMX_PYTHON`
selects the interpreter on another host. Runtime depends on the host;
the recorded complete execution took 154.68 minutes. Allow tens of GB of
free space for fresh circuit and physical-tool outputs.

`python scripts/restore_runtime.py --check` reports runtime files and host
executables. It does not install packages or start a design experiment.
`python scripts/verify_submission.py` checks the saved submission and can
run before restoring the large runtime inputs.

## Short check

With Python/NumPy, Icarus and KLayout installed:

```bash
python scripts/restore_runtime.py --layouts-only
python scripts/quick_review.py --root . --work /tmp/automx_submission_review
```

Use a new work directory for each run. This verifies frozen application
predictions, actual RTL and GDS hierarchy; it is not fresh analog signoff.
Original absolute paths in captured notebook outputs and reports are
historical provenance. Portable execution uses the current project root.
