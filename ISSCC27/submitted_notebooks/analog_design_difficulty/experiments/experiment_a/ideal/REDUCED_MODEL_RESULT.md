## Reading

With the same output capacitance, the same initial output error, and the same time axis, the input step starts with both `Vd` and `Vout` displaced, while the connection starts with `Vd` settled. The output transients do not collapse onto one waveform, as the analysis predicts. Shorter acquisition intervals fail for the connection (for example 10.63 mV at 15 ns); that is a timing-allocation effect and is not what establishes the port difference. The local ±20 % check is in `reduced_model_local_sensitivity.csv`. The model is a qualitative mechanism model, a counterexample: it shows that one additional internal state makes the two tests non-equivalent. It is not a quantitative macromodel of the SKY130 driver, and its values are not fitted to it.
