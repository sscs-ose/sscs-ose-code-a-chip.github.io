# 给主持人：交给同学前与收回后的步骤

尚无真实读者，不要把此清单标为已经完成。

1. 只交 `outputs/READER_TRIAL_V05.zip` 给同学。请先在你自己的浏览器解压试开，记录入口；作者自测不计入独立读者样本。不要发开发包中的 FACILITATOR.md、测试或答案记录。
2. 说明这是自愿试用，可随时停止，不要求名字、注册、安装 Python 或 EDA。给一个不识别个人身份的代号，并确认愿意记录/分享反馈。
3. 让同学先独立按 START_HERE.html 操作；不要预先讲解挑战答案。建议留 45–60 分钟，这是计划值，不是实验测得值。
4. 用 OBSERVER_FORM.txt 记录实际起止时间、入口、语言/术语障碍、每次提示原文。区分“独立完成”“有提示完成”“未完成”“未尝试”。静态任务成功不能记为动态控件成功。
5. 收回同意分享的 FEEDBACK_FORM.txt 与 TXT 笔记；JSON 可选。不要把机器自动测试记录或作者演练记录混入真实人类数据。没有记录的耗时留空。
6. 用 FACILITATOR.md 核对解释而非只数对错；错误预测本身不是失败，关键是能否据证据修正并迁移。
7. 将具体反馈对应到 REVISION_LOG.md，落实修改，再让读者复查相关部分；把原回答、提示、修订及复查保留在同一代号下。
8. 汇报实际人数和个体观察，不用一人样本推断普遍学习效果。完成试用但没有反馈驱动修订，仍未满足最终验收。

模板不是邀请发送授权。这里只准备材料，不自动联系同学或比赛方。
