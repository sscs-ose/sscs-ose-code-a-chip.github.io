# Replay saved RTL and the saved generic netlist without an LLM

This is an executable, deterministic-input reproduction path for the packaged
**P1 Counter**. It uses the exact adopted node RTL, adopted integration RTL,
saved generic synthesis netlist and original independent testbench. It does
not restore an old acceptance label into an editable project, regenerate RTL,
resynthesize a circuit or run any physical-design stage.

## Retained inputs

All paths below are relative to `submission/reproduction/p1_counter/`.

## 1. Inspect without executing a tool

Use Python 3.12 in the HuLLCirq folder:

```text
python scripts/replay_saved_example.py
```

Expected: `input_integrity: Passed`, 14 vectors, 42 required output samples,
50 ns clock and `simulator_started: false`. This operation needs no model,
PDK, EDA installation or network access.

## 2. Explicitly compile and simulate with Icarus 12.x

On a host with trusted Icarus Verilog 12.x and its sibling `vvp` installed in
PATH, run:

```text
python scripts/replay_saved_example.py --run
```

For an explicit native installation, use `--iverilog` to select its installed
executable. A native library-directory override is available as
`--base-directory`. These are local trusted installation choices; no executable
is loaded from a circuit evidence file.

On Windows, after the documented [first-use preparation](fresh_install.md)
has completed **in this checkout**, use the isolated Python and its prepared
WSL compiler profile:

```powershell
& '.work/runtime/python-3.12.10-embed-amd64/python.exe' -B -X utf8 `
  scripts/replay_saved_example.py --run --fresh-runtime
```

If preparation used a nondefault WSL distribution, pass the same
`--distribution` value. `--fresh-runtime` locates this checkout's configuration
using the exact same root/distribution binding as first-use preparation. It
does not download dependencies or change system settings.

Alternatively, `--compiler-config` accepts an explicitly selected **trusted
local** Icarus compiler profile previously generated by the preparation scripts.
Do not supply a configuration received from an untrusted evidence package.
Host-specific configuration files are intentionally absent from this submission.

## Result and scope

The script performs one Icarus version query, then two compilations and two
simulations. Both simulations use the exact same unmodified independent
testbench and original 50 ns timing:

| Source executed | Cycles | Required / checked output comparisons | Mismatches | Missing |
| --- | ---: | ---: | ---: | ---: |
| Adopted node RTL + integration RTL | 14 | 42 / 42 | 0 | 0 |
| Saved S09 generic netlist used by S10 | 14 | 42 / 42 | 0 | 0 |

Each output sample must appear in the exact saved order and match its original
expectation. The original hash-bearing pass marker must follow all 42 samples.
An absent marker, extra or missing sample, mismatch, compile failure or nonzero
process result fails the replay. A process exit code alone does not establish
functional success.

Submission preparation actually ran both paths using Icarus Verilog 12.0 on the
prepared Windows/WSL Ubuntu host. Both passed. The initial restricted execution
attempt could not query WSL; it produced no circuit result. A permitted local
execution then completed the five commands. Native-platform argument support
is implemented, but a separate Linux or macOS host was not tested here.

New simulation binaries, copied inputs and full local tool logs are saved in
unique directories below `.work/saved-rtl-replay/`. These local logs can contain
host paths and must not be published without review. Original project stores,
adoption records, source files and frozen expectations are never edited.

This is a finite, zero-delay RTL/generic-netlist functional replay. It does not
rerun S11-S14, establish dynamic SDF timing, replace extracted STA or constitute
foundry signoff. The full historical GUI flow and its later physical evidence
remain separate. **Projects -> Restore backup -> Duplicate** is an input-only
route for new GUI work, not the saved-RTL replay demonstrated on this page.
