## Project summary

An open-source educational laboratory built from a published **SKY130 Tiny Tapeout UART/VGA ASIC**. The notebook clones the original RTL at a pinned commit and combines a compact 32×6-bit message buffer, UART 8N1 timing, VGA 640×480 at 25.175 MHz, source-parsed 5×7 glyphs (4× scaled), a 2-bit ALU, and a link to the published physical layout. The aim is a transparent, executable teaching artifact connecting source RTL to reproducible verification and implementation evidence.

The project was **previously submitted to Tiny Tapeout SKY26c**. The present notebook provides an openly licensed, reproducible educational analysis.

**Upstream source:** https://github.com/nobleg30/ttsky26c-uart-vga-scroller

## Run the notebook

1. Upload `UART_VGA_Code_a_Chip_ISSCC27_MITS.ipynb` to [Google Colab](https://colab.research.google.com/) or launch it from GitHub.
2. Select **Runtime → Run all** with internet access. The notebook clones the original RTL, installs Icarus (if missing), and installs the original project Cocotb dependencies into the runtime. No login is required to clone the public source.
3. Keep `RUN_ORIGINAL_COCOTB = True` for the complete integrated RTL regression. This increases run time but is needed for the final four-check PASS summary.
4. Confirm the final verification manifest shows **4/4 PASS**. The original Cocotb suite contains **one integrated test case** with multiple internal checks, not four separate tests.
5. Verify the original Cocotb output frames appear after its test and download the executed notebook via **File → Download → Download .ipynb**. Save that **executed notebook** back into this directory before opening the submission pull request.
6. Optionally download `code_a_chip_execution_evidence.zip` (generated by the final notebook cell) to preserve current-session logs, original Cocotb frame captures and manifest.

The notebook uses `numpy`, `pandas`, `matplotlib`, and `ipywidgets`, which are usually available in Colab. Its RTL runs use Icarus Verilog, plus the upstream repository's pinned Cocotb requirements (`cocotb==2.0.1`, `pytest==8.4.2`). A Debian/Colab-like Linux environment with `git`, `make`, `apt-get`, and internet access is recommended.

## Detailed architecture diagram

The architecture is embedded in the `.ipynb` itself; a standalone PNG is also in `figures/`. The figure is an explanatory overview, not a transistor schematic or a machine-checked netlist. Refer to the frozen `src/project.v` for exact connectivity.

The TinyVGA `uo_out[7:0]` signals and independent ALU `uio_out[7:6]` signals are distinct; `uio_oe` is hardwired to `8'b11000000`. For precise bit-level wiring consult the original Verilog. See `figures/Architecture.png`.
