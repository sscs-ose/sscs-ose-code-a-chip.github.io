# Earlier stopped capacity study (diagnostic only)

Eight development pilots and five of 84 planned formal sessions ended before
admission was withdrawn for an asynchronous-tool lifecycle defect. One formal
session additionally records administrative interventions. These records are not
pooled with the complete historical PPA experiment or any new comparison.

This compact supplement retains original endpoint receipts, filtered accounting,
source snapshots and stop/replay records. Its archived hardware endpoints are
historical diagnostic observations; the complete stopped physical archive remains
preserved in the author workspace but is not part of this compact supplement.
No scientific claim in the main manuscript relies on those hardware endpoints.
The complete main-study physical evidence is included elsewhere in the submission.

For each `trials/<category>/<trial>` folder, the accounting can be replayed with
`diagnostics/submission-sprint/scripts/capacity_accounting_replay.py`, passing that
folder's `native-accounting.json` as `--packet` and `runtime` as `--runtime`.
Arithmetic agreement does not reverse the withdrawn admission or interventions.
