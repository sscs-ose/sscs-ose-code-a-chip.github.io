The nominal OTA differential input pair, tail, and active PMOS loads now use the included
sky130_fd_pr__nfet_01v8_lvt and sky130_fd_pr__pfet_01v8_lvt models so the 0.60 V, 0.30 V
common-mode bias has usable subthreshold headroom without requiring unphysical negative gate voltages.

ngspice compatibility defaults:
- The upstream TT files reference three absent zero-valued slope symbols in
  their raw form. The reduced wrapper pre-binds those symbols to zero before
  loading the official corner files. This is a compatibility workaround for
  the reduced bundle, not a replacement for a complete open_pdks installation.

The reduced wrapper includes only the four devices instantiated by the
NeuroDyn-AFE netlist and the official shared parameter files needed by them.
It is not a complete SKY130 PDK and must not be described as full PDK sign-off.
